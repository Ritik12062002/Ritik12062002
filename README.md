## 🚀 About Me

DevOps Engineer focused on cloud infrastructure, Kubernetes, Infrastructure as Code, CI/CD automation, observability, and infrastructure reliability.

I have 1.5+ years of hands-on experience with cloud platforms, Kubernetes and K3s, CI/CD pipelines, Terraform and Ansible, Linux administration, and monitoring. I like building systems that are automated, repeatable, and easy to troubleshoot.

This profile hosts my personal projects, practice labs, and learning notes.

## 🛠️ What I Do

- ☁️ Work with cloud infrastructure on **AWS, OpenStack, and GCP**
- ☸️ Deploy and troubleshoot applications on **Kubernetes, K3s, and EKS** using **Helm**
- 🏗️ Automate infrastructure with **Terraform** and **Ansible**
- 🔁 Build CI/CD pipelines with **GitLab CI/CD** and **GitHub Actions**, and practice GitOps with **Argo CD**
- 📊 Set up monitoring and logging with **Prometheus, Grafana, Loki, Tempo, and ELK/OpenSearch**
- 🔐 Add security and quality scanning with **SonarQube** and **Trivy**
- 🐧 Work with **Linux, networking, and load balancing** (Nginx, HAProxy, Keepalived)
